# Как помочь

Спасибо, что хотите улучшить ЮрИИст MCP. Этот репозиторий — stdio-мост и
документация; сам MCP-сервер (инструменты, поиск, ответы ИИ-юриста) закрыт и
работает на `app.yriist.ru`.

## Что сюда, а что нет

- **Сюда:** ошибки моста и входа, новые клиенты в `yriist-mcp config`,
  документация, совместимость с MCP-клиентами.
- **Не сюда:** качество ответов, содержание инструментов, тарифы — пишите на
  support@yriist.ru или в поддержку в приложении.
- **Уязвимости** — только по [SECURITY.md](SECURITY.md).

## Разработка

Нужен Node.js ≥ 18.17. Зависимостей нет — и так должно остаться: пакет
запускают через `npx`, каждая зависимость — это время старта и поверхность
атаки.

```sh
git clone https://github.com/Yriist/yriist-mcp.git && cd yriist-mcp
npm test
node bin/yriist-mcp.mjs --help
```

Тесты (`node:test`) поднимают мок-сервер OAuth + MCP и не ходят в сеть. На
каждое изменение поведения — тест.

`docs/tools.md` не правится руками: он собирается из `tools/list` сервера
командой `npm run docs:tools` (нужен вход со всеми правами).

## Правила кода

- ES-модули, без сборки и без TypeScript: файл в репозитории — это файл,
  который исполняется.
- В stdout — только JSON-RPC. Всё остальное — в stderr.
- Токены не логируются. Сообщения пользователю — на русском.
- Сетевая ошибка не должна стирать сохранённый вход или открывать браузер.

## Pull request

Один PR — одно изменение. Опишите, что было не так и как проверить. Добавьте
строку в `CHANGELOG.md`. CI (тесты на Node 18–24, Linux / macOS / Windows)
должен быть зелёным.

Присылая изменение, вы соглашаетесь на его публикацию под лицензией MIT.
