# Безопасность

## Как сообщить об уязвимости

Сообщите приватно: GitHub → Security → **Report a vulnerability** в этом
репозитории, или письмом на **support@yriist.ru** с темой «Security».
Не создавайте публичный issue, пока уязвимость не закрыта. В сообщении: что затронуто (этот пакет, сервер
`app.yriist.ru/api/mcp`, вход OAuth), шаги воспроизведения и возможные
последствия.

## Что хранит пакет

- `~/.config/yriist/credentials.json` (или `$XDG_CONFIG_HOME/yriist/`), права
  `0600`: идентификатор зарегистрированного клиента, access- и refresh-токен
  OAuth. Запись атомарная (файл + переименование).
- Личный токен читается из `YRIIST_TOKEN` или `~/.config/yriist/token`; пакет
  его не записывает.

Токены никогда не выводятся в stdout / stderr и не передаются никуда, кроме
сервера из `--url` / `YRIIST_MCP_URL` (по умолчанию `https://app.yriist.ru`).
Пакет отказывается работать с адресом `http://`, если это не `localhost`.

## Модель угроз входа

- Код авторизации принимается только на `127.0.0.1`, только с верным `state`
  и (когда сервер его объявляет) `iss`; обмен кода защищён PKCE S256.
- Refresh-токены одноразовые: при каждом обновлении сервер выдаёт новый.
- `logout` отзывает подключение на сервере и удаляет запись из файла.
  Отозвать доступ можно и в приложении: «Аккаунт → Подключения».

## Поддерживаемые версии

Исправления выходят для последней опубликованной версии.
