# Инструменты ЮрИИст MCP

Сгенерировано из `tools/list` сервера. Право — OAuth scope, без которого инструмента нет в списке.

## ИИ-юрист (`yriist:agent`)

### `ask_yriist` — Спросить ИИ-юриста ЮрИИста

Задаёт вопрос ИИ-юристу ЮрИИста — полноценный юридический агент по праву РФ: сам ищет судебную практику и нормы, проверяет ссылки, считает сроки и суммы и может составить документ (претензию, иск, договор). Ответ сохраняется чатом в ЮрИИсте (пользователь увидит его в приложении). Расходует одно сообщение тарифа. Для продолжения разговора передай chat_id. Ответ может готовиться до нескольких минут: при status=running вызови chat_read позже. Используй для сложных юридических вопросов целиком; для точечных проверок есть court_search, law_article, calculate_*.

Параметры: `question`, `chat_id`?, `deep_research`?, `wait_seconds`? · карточка: `ui://yriist/answer.html`

## Ваши данные (чтение) (`yriist:read`)

### `whoami` — Мой аккаунт ЮрИИста

Аккаунт ЮрИИста, к которому подключено это приложение: имя, тариф, сколько сообщений осталось в этом месяце, что доступно (глубокий поиск, документы) и выданные права подключения. Вызывай, чтобы понять, что пользователь может сделать в ЮрИИсте, или когда он спрашивает про свой тариф.

Параметры: — · карточка: `ui://yriist/account.html` · только чтение

### `chats_list` — Чаты ЮрИИста

Последние чаты пользователя с ИИ-юристом ЮрИИста (личное пространство): id, название, дата, ссылка. Для текста чата — chat_read; для поиска по словам внутри переписки — chats_search.

Параметры: `limit`?, `offset`? · карточка: `ui://yriist/list.html` · только чтение

### `chat_read` — Прочитать чат

Текст чата с ЮрИИстом в Markdown (вопросы пользователя и ответы ЮрИИста). Также проверяет, готов ли ответ после ask_yriist со status=running.

Параметры: `chat_id`, `max_chars`? · карточка: `ui://yriist/answer.html` · только чтение

### `chats_search` — Поиск по чатам

Полнотекстовый поиск по переписке пользователя с ЮрИИстом (русская морфология): найдёт, где обсуждались слова, суммы, стороны. Возвращает фрагменты и chat_id.

Параметры: `query`, `limit`? · карточка: `ui://yriist/list.html` · только чтение

### `documents_list` — Документы ЮрИИста

Документы пользователя в ЮрИИсте («Документы»): договоры, претензии, иски, созданные в чатах, из шаблонов или загруженные. Фильтр по названию. Текст — document_read.

Параметры: `query`?, `limit`?, `offset`? · карточка: `ui://yriist/list.html` · только чтение

### `document_read` — Прочитать документ

Текст документа из «Документов» ЮрИИста (последняя версия), с номерами абзацев. Таблицы — как CSV.

Параметры: `document_id`, `max_chars`? · только чтение

### `templates_search` — Шаблоны документов

Поиск по библиотеке из 230+ проверенных шаблонов ЮрИИста (договоры, иски, претензии, доверенности, заявления…). Смысловой поиск. Категории: Договоры, Исковые заявления, Претензии, Заявления, Доверенности, Акты, Расписки, Соглашения, Жалобы, Ходатайства и возражения, Согласия, Корпоративные документы, Уведомления, Кадровые документы, Письма и запросы, Коммерческие документы. Текст шаблона — template_read; копия в документы пользователя — document_from_template.

Параметры: `query`, `category`?, `limit`? · карточка: `ui://yriist/list.html` · только чтение

### `template_read` — Текст шаблона

Полный текст шаблона из библиотеки ЮрИИста: структура, обязательные реквизиты, ссылки на нормы. Используй как основу документа.

Параметры: `template_id` · только чтение

### `deadlines_list` — Сроки

Сроки пользователя из «Сроки» ЮрИИста: процессуальные и договорные, с последним днём, основанием (норма) и делом. По умолчанию — открытые, ближайшие первыми. Новый срок — deadline_save; отметить выполненным — deadline_complete.

Параметры: `status`?, `due_from`?, `due_to`?, `limit`? · карточка: `ui://yriist/deadlines.html` · только чтение

### `cases_list` — Дела на мониторинге

Судебные дела, которые ЮрИИст отслеживает для пользователя («Дела»): номер, суд, стороны, последнее событие, открытые сроки. Поставить новое — case_track.

Параметры: `status`? · карточка: `ui://yriist/list.html` · только чтение

### `memory_search` — Поиск в памяти ЮрИИста

Факты о пользователе и деле из прошлых разговоров (стороны, суммы, даты, номера, предпочтения), когда их нет в контексте.

Параметры: `query`, `scope`? · карточка: `ui://yriist/research.html` · только чтение

## Действия (`yriist:write`)

### `document_create` — Создать документ в ЮрИИсте

Сохраняет готовый текст (Markdown: заголовки, списки, таблицы, **жирный**) как документ в «Документы» ЮрИИста — там его можно править в редакторе, скачать DOCX/PDF, подписать и отправить. Возвращает ссылку. Используй, когда пользователь просит сохранить или оформить документ в ЮрИИсте.

Параметры: `title`, `content` · карточка: `ui://yriist/list.html`

### `document_from_template` — Документ из шаблона

Копирует шаблон из библиотеки в «Документы» пользователя, чтобы заполнить его в редакторе ЮрИИста. Возвращает ссылку на новый документ.

Параметры: `template_id`, `title`? · карточка: `ui://yriist/list.html`

### `deadline_complete` — Срок выполнен

Отмечает срок в «Сроки» ЮрИИста выполненным (status=done) или снимает с контроля (dismissed); reopen — вернуть в работу. Напоминания по нему прекращаются.

Параметры: `deadline_id`, `status`? · карточка: `ui://yriist/deadlines.html`

### `memory_save` — Запомнить в ЮрИИсте

Сохраняет факты в долговременную память; каждый — самодостаточное утверждение с конкретикой («Работодатель — ООО «Ромашка», ИНН 7701234567»).

Параметры: `facts` · карточка: `ui://yriist/research.html`

### `memory_delete` — Забыть в ЮрИИсте

Удаляет устаревшие или ошибочные факты по id (chat:…, project:…, profile:… — из контекста или memory_search), когда просят забыть или факт изменился.

Параметры: `ids`, `reason` · карточка: `ui://yriist/research.html`

### `deadline_save` — Сохранить срок

Сохраняет процессуальный или договорной срок в «Сроки» ЮрИИста с напоминаниями (push, email, календарь). Последний день пересчитывается движком сроков по производственному календарю — тот же, что в calculate_deadline. Только по просьбе пользователя сохранить или напомнить.

Параметры: `rule`?, `procedure`?, `length_value`?, `length_unit`?, `day_kind`?, `event_date`, `alt_event_date`?, `title`?, `case_number`?, `note`? · карточка: `ui://yriist/deadlines.html`

### `case_track` — Отслеживать дело

Ставит судебное дело на мониторинг в «Дела» ЮрИИста: новые акты приходят уведомлением, сроки обжалования попадают в «Сроки». Номер и суд — из court_case. Только по просьбе пользователя.

Параметры: `case_number`, `court`?, `uid`?, `title`? · карточка: `ui://yriist/research.html`

## Исследование и расчёты (`yriist:research`)

### `web_search` — Поиск в интернете

Поиск в российском интернете (Яндекс и др.) через ЮрИИст. До 4 запросов за вызов. Результаты с номерами [n] — откройте лучшие через web_fetch по номеру и опирайтесь на прочитанный текст, а не на сниппеты.

Параметры: `queries`, `recency`? · карточка: `ui://yriist/research.html` · только чтение

### `web_fetch` — Чтение страниц

Читает веб-страницы и документы по ссылке: результаты web_search, court_search и court_case по номеру [n] или любую публичную страницу по полному URL (http/https). Небольшие источники возвращаются целиком, большие — частями: укажи query, чтобы получить релевантные части, или parts с номерами частей. До 5 источников за вызов. Числа (проценты, суммы, сроки, даты) бери только из прочитанного текста. Для страниц, где нужен вход или действия, используй браузер.

Параметры: `sources` · карточка: `ui://yriist/research.html` · только чтение

### `court_search` — Судебная практика

Судебная практика РФ по смыслу (СОЮ, арбитраж, ВС с Пленумами и обзорами, часть КСОЮ): лучшие решения [n] с мотивировкой и итогом. Дело по номеру, УИД или ссылке — court_case; полный текст — read с query.

Параметры: `query`, `category`?, `court_level`?, `court`?, `judge`?, `article`?, `doc_type`?, `instance`?, `party`?, `party_role`?, `date_from`?, `date_to`?, `outcome`?, `list`?, `alt_queries`? · карточка: `ui://yriist/research.html` · только чтение

### `court_case` — Карточка дела

Решение по номеру дела, УИД или ссылке: база с учётом суда и нижестоящей инстанции, иначе официальные сайты. Пользователь назвал дело — сначала court_case, не court_search.

Параметры: `case_number`?, `uid`?, `url`?, `court`?, `date`? · карточка: `ui://yriist/research.html` · только чтение

### `law_article` — Текст нормы

Текст статьи кодекса или закона (или пункта Пленума ВС/ВАС) в действующей редакции, сверенный по нескольким источникам, с номером [n]. Знаешь акт и статью — бери здесь, не поиском. В базе кодексы, 96 основных законов (по номеру или названию: «127-ФЗ», «ЗоЗПП»), ПДД РФ (article — пункт: «12.4») и Пленумы (по номеру и дате). Закона нет в базе — укажи вид, дату и номер («Федеральный закон от 27.11.2018 № 422-ФЗ»), так найдётся и он; у постановления Правительства article — пункт утверждённых им Правил. В ответе «Рядом в этом акте»: если нужного (срока, суммы, условия, круга лиц, исключения) в статье нет, открой соседнюю, прежде чем отвечать.

Параметры: `articles` · карточка: `ui://yriist/research.html` · только чтение

### `check_norms` — Актуальность норм

Актуальность норм: по каждой ссылке в тексте — утратила силу (и что вместо), не вступила (с какой даты), недавно изменена, нет такой статьи или части. Когда просят проверить ссылки в документе (file), и для своего черновика со старыми или редкими нормами. ✗ — не приводи норму как действующую.

Параметры: `text`?, `file`?, `citations`? · карточка: `ui://yriist/research.html` · только чтение

### `verify_claims` — Проверка ссылок и цифр

Проверка ссылок и цифр перед итоговым ответом на правовой вопрос: нормы, Пленумы и дела существуют, часть и подпункт есть, числа совпадают с текстом, решающая норма не специальная другая, итог дела верен. Выводы «нельзя / не вправе / обязан / не требуется / только» сверяет со всей статьёй — передавай их с нормой. Пересчитывает сроки (срок + дата начала + последний день), госпошлины и «a × b = c». ✗ — исправь вывод по тексту и проверь снова.

Параметры: `claims` · карточка: `ui://yriist/research.html` · только чтение

### `company_lookup` — Карточка компании

Карточка компании или ИП из ЕГРЮЛ/ЕГРИП: наименование, ИНН, ОГРН, КПП, адрес, руководитель, статус. По ИНН/ОГРН — точно, по названию — до 5 вариантов. Учредители, суды, долги, риски — company_check.

Параметры: `query` · карточка: `ui://yriist/research.html` · только чтение

### `company_check` — Проверка контрагента

Проверка контрагента по открытым реестрам: учредители, недостоверность, массовость, дисквалификация, РНП, санкции, банкротство, недоимка, суды, ФССП, отчётность, госзакупки, история изменений. Физлицо по ИНН (target=person) — где руководитель или учредитель. Платный: только когда просят проверить контрагента, оценить риски сделки или найти суды и долги; реквизиты — company_lookup.

Параметры: `query`, `target`?, `sections`? · карточка: `ui://yriist/research.html` · только чтение

### `requisites_lookup` — Реквизиты

Справочные реквизиты: bank — по БИК, ИНН или названию; court — по названию, коду или «судебный участок N город»; tax_office — по коду, названию или адресу; address — нормализация (индекс, ОКТМО, ОКАТО, ИФНС, кадастровый номер).

Параметры: `kind`, `query` · карточка: `ui://yriist/research.html` · только чтение

### `calculate_penalty` — Расчёт неустойки

Проценты и неустойки за просрочку денежного обязательства по ключевой ставке: периоды, моратории, частичные оплаты, риск снижения по ст. 333 ГК.

Параметры: `type`, `debt_rub`, `start_date`, `end_date`, `subject`?, `payments`?, `contractual_rate_percent`?, `contractual_rate_period`?, `zozpp_claim`?, `contract_price_rub`? · карточка: `ui://yriist/research.html` · только чтение

### `calculate_court_fee` — Расчёт госпошлины

Госпошлина по действующему НК РФ (ст. 333.19, 333.21) с льготами. Ставка зависит от вида производства, не от суда: жалоба в ВС — supreme_court_complaint с court по виду дела. Моральный вред — не в claim_amount_rub, а в non_property_claims. КБК не называй: реквизиты — на сайте суда.

Параметры: `court`, `claim`, `separate_dispute_claim`?, `payer`, `bankruptcy_applicant`?, `claim_amount_rub`?, `non_property_claims`?, `payer_status`?, `filing_date`? · карточка: `ui://yriist/research.html` · только чтение

### `calculate_deadline` — Расчёт процессуального срока

Срок по производственному календарю РФ (2020–2027): дни по правилу кодекса, месяцы, годы, перенос с выходных, статус на сегодня. Любой срок с датой считай здесь, не в уме. Неясно, от какого события считать (вынесение, полный текст, получение копии), — передай обе даты. rule: кодекс.вид; cassation — в КСОЮ или АС округа, presidium_cassation — в президиум областного суда, vs_cassation — в СК ВС, simplified_motivated — заявление о мотивированном решении. Нет правила — procedure и length_value/length_unit.

Параметры: `rule`?, `procedure`?, `length_value`?, `length_unit`?, `day_kind`?, `event_date`, `challenged_act`?, `alt_event_date`? · карточка: `ui://yriist/research.html` · только чтение

### `calculate` — Точный расчёт

Точная арифметика (суммы, доли, проценты, деньги до копейки): каждое число ответа бери отсюда. Шаг — формула с числами и именами прошлых шагов. Десятичная запятая («0,4484»), «%» — сотая доля, round(x; 2), min, max; без round не округляет. Метод (method) выбираешь ты; есть расчёт пользователя — сначала воспроизведи его, другой метод — только с нормой или практикой.

Параметры: `method`, `steps`, `share_denominator`?, `sum_check`? · карточка: `ui://yriist/research.html` · только чтение

### `skill_read` — Навык ЮрИИста

Читает встроенный навык ЮрИИста — проверенный порядок работы для частой юридической задачи (претензия, иск, проверка договора, расчёт сроков…). Прочитай навык, если задача под него подходит, и следуй ему.

Параметры: `name` · карточка: `ui://yriist/research.html` · только чтение
